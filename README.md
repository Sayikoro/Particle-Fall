## Особенности

- **Система частиц на холсте** — плавная анимация `requestAnimationFrame` с дрейфом, колебанием, вращением и прозрачностью
- **метаданные presets.json** — дополнительные метки интернационализации и пользовательские цвета для каждого пресета
- **Цветовая тонировка** — выберите любой цвет, частицы тонируются с помощью композиции `source-atop` на холсте
- **Предварительный просмотр в реальном времени** — предварительный просмотр холста в реальном времени в панели администратора. Измените любую настройку и мгновенно увидите результат
- **Темная/Светлая тема** — переключение одним щелчком, настройки сохраняются для каждого пользователя
- **Недавние частицы** — последние 12 использованных частиц сохраняются в localStorage для быстрого доступа
- **Поддержка SVG** — загрузка SVG через медиатеку WordPress, безопасный рендеринг Blob URL, очистка от XSS
- **Совместимость с Elementor** — просто добавьте класс CSS в разделе → Расширенные настройки → Классы CSS
- **Tailwind CSS** — нулевой пользовательский CSS, весь административный интерфейс через CDN Tailwind (предварительная проверка отключена)
- **MutationObserver** — обнаруживает динамически добавляемый контент Elementor
- **DPR-совместимость** — четкое отображение на дисплеях Retina (ограничено 2x)

## Технические характеристики Подробности

### Система частиц
- **Рендеринг**: HTML5 Canvas 2D с `requestAnimationFrame`
- **Физика**: скорость каждой частицы, дрейф (горизонтальный), колебание (синусоидальное), вращение, прозрачность
- **Цветовое тонирование**: `globalCompositeOperation = 'source-atop'` — накладывает цветовой слой только на существующие пиксели
- **DPR**: `Math.min(devicePixelRatio, 2)` для четкого рендеринга без снижения производительности
- **Динамический контент**: `MutationObserver` отслеживает добавленные Elementor элементы, соответствующие классу CSS

### Безопасность SVG
- Тип MIME для загрузки белый список (`image/svg+xml`)
- Фильтр `wp_check_filetype_and_ext` для корректного определения типа
- При загрузке: удаляет `<script>`, `<?xml?>`, обработчики событий `on*`, `javascript:` и опасные HTML-элементы (`<iframe>`, `<object>`, `<embed>` и т. д.)

## Требования

- WordPress 5.0+
- PHP 7.4+
- Современный браузер (Canvas API, ES6+)
